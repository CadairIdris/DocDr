# Assets

`DocDr.ico` — the app icon (16–256 px, PNG-compressed entries). A white document with a
folded corner and an orange "＋" on DocDr's purple, i.e. *Document Doctor*. Wired up via
`<ApplicationIcon>` (the .exe) and `Window.Icon` (title bars).

Regenerate by editing colours/geometry in the throwaway GDI+ script used to build it
(`scratchpad/reflect/Program.cs` in the session that added it) or any icon editor — keep the
same size set.
